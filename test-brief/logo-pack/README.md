# Banksia Build Co. logo pack

Illustrative brand assets for the test brief. The mark is a square-edged B monogram: a teal spine (a carpenter's square edge) and two warm bowls. All artwork is original and made for this test.

| Folder | Contents |
|---|---|
| `svg/` | Master logos: `logo-horizontal`, `logo-stacked`, `mark`, each in `on-dark`, `on-light`, `white`, `black` |
| `png/` | Transparent PNG exports of every logo at native size (2x for print: re-export from SVG) |
| `favicon/` | `favicon.svg`, `apple-touch-icon.png` (180), `icon-32/192/512.png`, `icon-512-maskable.png` |
| `social/` | Open Graph 1200x630, square post 1080, story 1080x1920, Facebook cover 1640x624, LinkedIn banner 1584x396, avatar 800. Light and dark each |
| `headers/` | Hero 1920x1080, mobile hero 900x1125, page header 1920x420, blueprint page header 1920x420. Light and dark each, WebP |

## Usage

- **on-dark** on Ink or Slate; **on-light** on Sand; **white** or **black** on photography and brand-colour fills.
- Clear space: the width of the spine on every side. Minimum width: mark 20 px, horizontal lockup 120 px.
- Never recolour, outline, stretch, rotate or add effects.

## Notes

- Wordmark text in the SVGs uses Barlow Condensed and DM Mono, embedded as base64 woff2 so the files render anywhere without installing fonts. They are not outlined: convert text to paths in a vector editor before sending to print.
- Social images are PNG (platforms want PNG or JPG). Headers are WebP, ready for `public/images/`.
- The scenes are illustrative stand-ins for photography. Replace with real project photos.
- On light backgrounds the on-light Ember and Surf are for graphics (logos are exempt from text contrast); use the deep text colours from the brief for text.
